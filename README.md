# 심연으로

2D 탑뷰 던전 파밍 액션 RPG. 브라우저에서 바로 실행돼요(설치 없음).

- 컴퓨터: 방향키 이동 · X 공격 · C 대시 · V 회전베기 / 마법진 · Z 특수기 · 1 물약 · I 가방 · Esc 메뉴 (패드도 됨)
- 폰: 가로로 돌리면 왼쪽 스틱 · 오른쪽 버튼
- 기록은 그 브라우저에 저장돼요. 다른 기기로 옮기려면 캐릭터 선택 화면의 "코드로 내보내기 / 불러오기"를 쓰세요.
